# v2.6.1: stay signed in for 7 days on Claude

After a Claude account switch, Claude's connector got a 401 from `/mcp` for an
expired server token and went straight to a new Google sign-in, without first
trying its refresh token. The server token lived as long as Google's access
token, about an hour, so this could happen after any idle hour.

## Changed

- **The server token now lasts 7 days** (`ACCESS_TOKEN_TTL_SECONDS` in
  `http_mode.py`). slides-mcp still checks the caller's Google grant on every
  request and refreshes Google's access token itself when it expires, so a
  revoked grant still stops working within the hour. Seven days matches the limit Google puts
  on refresh tokens while the OAuth app is in Testing mode.

## Upgrade notes

- HTTP mode (`serve-http`) only; stdio is unchanged.
- Nobody needs to sign in again. Existing sign-ins get the 7-day token at
  their next refresh.
