*Released 2026-04-23. Ships `audit_typography`, `restyle_slides`, `list_icons`,

## Brownfield loop — audit, repaint, verify

```
get_theme_brief(deck)             # is there a brief?
  → if None: extract_theme_brief → review → set_theme_brief

audit_deck_colors(deck)           # drift vs theme
audit_typography(deck)            # dominant font, size clusters, orphan bolds,
                                  # color drift vs BRIEF

restyle_slides(
    deck, slide_ids="all",
    brief_overrides={"palette": {"accent": "#6B21A8"}},
    confirm_destructive=True,
)                                 # repaint in one call

render_thumbnail(slide_id) × restyled  # verify one-voice

update_theme_brief(changes=...)   # persist if overrides should stick
```

`audit_typography` and `restyle_slides` share the **same 60 RGB-distance
threshold** — “what the audit reports” == “what restyle will rewrite.”
Near-black text (body) and near-white text (inverted titles) are
preserved; they express hierarchy, not identity.

## Vanilla icons — probed, pivoted, delivered

The initial design bundled Phosphor SVGs to embed inline via `createImage`.
The v0.6.0 probe hit a wall fast: **Slides API rejects inline
`data:image/svg+xml` URLs** (400 “URL is invalid”). A CDN-hosted SVG would
work but violates the “no external deps” contract (user's pre-approved
fallback called out this exact case).

Pivoted to **Slides API native shape composition**. Each icon maps to 1–N
Shape.Type primitives (`RIGHT_ARROW`, `STAR_5`, `HEART`, `LIGHTNING_BOLT`,
composed `RECTANGLE`s for charts, layered `ELLIPSE`s for targets).

| Property | Outcome |
|----------|---------|
| Zero external deps | ✓ native Slides rendering |
| Theme-color native | ✓ defaults to `brief.palette.accent` |
| Scales perfectly | ✓ vector primitives |
| Drop-in extensibility | ✓ edit `src/slides_mcp/icons/registry.yaml` |
| Offline-safe | ✓ no network |

**Catalog (v0.6.0, 30+ icons)**: arrow-{right,left,up,down}, plus, minus,
multiply, divide, equal, not-equal, star, heart, bolt, ribbon, no-entry,
sun, moon, cloud, smiley, circle, square, rounded-square, triangle,
right-triangle, diamond, pentagon, hexagon, octagon, chart-up, chart-down,
target, bullseye, stack.

Per-shape `fill_hex` overrides in the registry let layered icons (target,
bullseye) render as rings rather than solid discs.

## Archetype integration

`3col_pill_cards` gains optional `icon_names: [str × 3]`. Each icon renders
above its pill, **auto-colored to match the pill** (via `_pill_hex` fall-
through — pill_hex → brief.category_set → theme default). Icon REPLACES the
default dot accent when present; absent icons fall back to dots. Unknown
names are silently skipped (partial delivery > failed slide).

`text_left_image_right` icon overlay is deferred to v0.6.1 — scope honesty
over scope creep. Call `create_icon` after `create_slide` for now.

## Before / after (brief-driven pill card with icons)

```yaml
# v0.5.0 — manually per-slide
create_slide(archetype="3col_pill_cards", content={
    title: "Pillars",
    columns: [
        {pill: "Reliability", pill_hex: "#B45309", body: "…"},
        {pill: "Velocity",    pill_hex: "#134E4A", body: "…"},
        {pill: "Clarity",     pill_hex: "#A16207", body: "…"},
    ],
})
# + manual create_shape × 3 if you wanted icons above each

# v0.6.0 — brief + icons
set_theme_brief(deck, brief)      # once per deck
create_slide(archetype="3col_pill_cards", content={
    title: "Pillars",
    columns: [
        {pill: "Reliability", body: "…"},   # pill color from brief
        {pill: "Velocity",    body: "…"},
        {pill: "Clarity",     body: "…"},
    ],
    icon_names: ["shield-pentagon", "bolt", "chart-up"],  # auto-colored
})
```

## Known issues + v0.6.1 punchlist

- `restyle_slides` now uses a per-slide `get_slide` fetch (SLIDE_FULL_FIELDS)
  to avoid an outline-mask edge case that under-detected fills on text-
  containing ROUND_RECTANGLE pill shapes in the initial smoke test.
- `text_left_image_right` icon_name overlay — not yet landed.
- Clean projectors for `4col_numbered_flow` and `4col_card_with_image` —
  still fall through to faithful mode, so `restyle_slides` surgical path
  on those archetypes uses the faithful walk (works; just coarser).
- Brownfield font normalization — brief doesn't carry font yet; fonts
  stay theme-YAML-controlled.
- Round-5 intern gate (eval_E_brownfield_* + eval_E_icons_*) — deferred
  to next session fork per autonomous context budget. Live smoke test on
  sandbox passed for all four new tools.
