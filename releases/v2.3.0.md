# v2.3.0 — Install the agent skill by asking for it

slides-mcp ships an agent skill: when to use `run_deck_script`,
`write_speaker_notes` or `exec_batch_update`, the Request cheat sheet and
worked examples. Until now you had to find it in the repo and copy it by hand,
and the PyPI package did not contain it at all. v2.3 serves it from the server.

## New: `install_skill`

Ask your agent to "install the slides-mcp skill". The tool returns:

- **every skill file** with its path, matching the version of the server you
  are connected to;
- **where skills go** for Claude Code, Codex CLI and Gemini CLI, user-wide and
  per project (other agents ask you);
- **steps for the agent:** ask you user or project, delete any old copy, write
  the files, and tell you a restart may be needed. Agents that cannot write
  files use the content for the current conversation and say so;
- a link to the same skill at this release's tag on GitHub, for reading.

It needs no deck and no Google sign-in. Ask again after upgrading the server
to update the skill.

Team onboarding with only an endpoint URL is now two steps:

1. Add the slides-mcp endpoint to your agent and complete the sign-in.
2. Ask your agent: "install the slides-mcp skill".

## Fixed: fresh installs failed to start

`mcp` 2.x renamed `FastMCP`, and a fresh `uvx slides-mcp` resolved it, so the
server exited with `No module named 'mcp.server.fastmcp'`. The dependency is
now `mcp[cli]>=1.2.0,<2`.

## Upgrade notes

- No changes to existing tools or arguments.
- The wheel now includes the skill folder under `slides_mcp/_skills_data/`.
