# v0.4.0 — Release workflow now publishes hand-written notes

The release workflow previously rendered an auto-generated commit categorization (Features / Bug Fixes / Other Changes / Diff Summary) into the GitHub Release body, ignoring the curated `releases/vX.Y.Z.md` files that already lived in the repo. From this version on, the workflow requires `releases/${tag}.md` and pipes it verbatim into `gh release create --notes-file`, matching the npm-side narrative pattern.

No code changes — workflow-only fix. Bumped to a minor to make the behavior change discoverable in the tag log.
