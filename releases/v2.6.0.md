# v2.6.0: checks an agent can read, and create_deck

An agent in ChatGPT asked for a row of text boxes. Every box landed in the
top-left corner as a 3.3 in square, the write reported success, and the agent
said it had checked the result. Two things combined: the agent passed inches
where the Slides API takes EMU, which Google accepts silently by substituting
its default size, and ChatGPT's model cannot see the thumbnail a write
returns. We confirmed the second with a test slide: ChatGPT received the image
intact, then either said it could not read it or described shapes and colours
that were not there. This release refuses the mistake before it is written
and reports layout problems as text, which every client's model can read.

## New

- **`create_deck(title)`.** Creates a new, empty deck in the signed-in user's
  Drive root and returns its id, URL, first slide id and outline. It needs no
  new sign-in. There is no folder or template option: that would need a Drive
  write scope.
- **Inch guard.** A create whose width or height is under 1 pt (12,700 EMU),
  or not a number, is refused before anything is sent, with a message that
  asks whether inches were passed and gives the conversion. It applies to
  `exec_batch_update` (dry runs included), `run_deck_script` (dry runs
  included) and every other write. Lines are exempt. In scripts, `textBox`,
  `resize` and `move` throw the same message at the line that called them.
- **Layout warnings after writes.** A write's `warnings` now names each
  element it created that sits at Google's default 3.281 in square, that is
  stacked exactly on two or more other new elements, or that is partly or
  fully off the page, with its id and position in inches. Elements that were
  already in the deck are never reported.
- **Tool hints.** Every tool declares whether it is read-only, destructive,
  idempotent and open-world. Clients that showed every tool as destructive,
  including ChatGPT, now see the six read tools as read-only.

## Changed

- `read_slides(detail="raw")` adds a top-level `units` line: `at` is in
  inches, writes take EMU.
- Write receipts carry `thumbnails.note`, and `render_thumbnail` sends a text
  line before its image: "If you cannot see the image(s) below, say so. Do
  not describe them."
- A script error raised inside a helper now reports the line in your script,
  not a line in the helper library.
- A real `run_deck_script` apply that creates elements reads the deck once
  more, for the layout check.

## Upgrade notes

- `render_thumbnail` now returns two content blocks, text then image. A
  client that expected exactly one image block should read the last block.
- Requests that relied on Google's default size by sending a tiny one are
  now refused; send the size you want.
